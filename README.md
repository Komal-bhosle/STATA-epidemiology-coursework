# STATA Advanced Epidemiology Coursework
This repository contains laboratory assignments completed as part of an Advanced Epidemiology course during my MPH program.

Each Lab Includes:
A '.do' file with annotated stata code
A '.log' file showing analytical output
A written interpretation of results

## Labs Included
Lab 01 - Descriptive Epidemiology
Lab 02 - Linear Regression
Lab 03 - Screening Test
Lab 04 - Logistic Regression
Lab 05 - Missing Data
Lab 06 - Survival Analysis
Lab 07 - Effect modification & Confounding

## Skills Demonstrated
Data Cleaning and Validation
Descreptive Epidemiology
Regression Modeling and interpretation
Critical Analysis of Epidemiologic results
